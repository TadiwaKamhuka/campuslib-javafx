# CampusLib — UI Style Guide

This document defines the locked visual standards for the CampusLib JavaFX application. All screens must follow these rules.

---

## 1. Color Palette

* **Primary Blue:** `#1D4ED8` (Used for primary action buttons, selected nav items)
* **Primary Blue Hover:** `#1E40AF`
* **Background:** `#F8FAFC`
* **Surface / Card Background:** `#FFFFFF`
* **Sidebar Background:** `#FFFFFF`
* **Sidebar Active Item:** `#EFF6FF`
* **Main Text:** `#0F172A`
* **Secondary Text:** `#64748B`
* **Border Color:** `#E2E8F0`
* **Success Green:** `#16A34A`
* **Warning Amber:** `#D97706`
* **Danger Red:** `#DC2626`

---

## 2. Typography

The application uses the default JavaFX system font.

* **Page Title:** 24px, Bold (`#0F172A`)
* **Section Title:** 18px, Bold (`#0F172A`)
* **Body Text:** 14px, Normal (`#0F172A`)
* **Secondary Text:** 12–13px (`#64748B`)
* **Table Header:** 13px, Bold (`#64748B`)

---

## 3. Layout & Components

* **Sidebar:** Fixed width of 240px on the left side of main screens.
* **Stat Cards:** White background, rounded corners, light border, 4 cards per row on the dashboard (Books, Members, Active Loans, Overdue Loans).
* **Buttons:**
  * **Primary Action:** Blue filled button (`#1D4ED8`)
  * **Secondary Action:** White button with gray border
  * **Destructive Action:** Red filled button (`#DC2626`)
