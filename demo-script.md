# CampusLib — Final Presentation & Demo Script

This script defines the required step-by-step flow for demonstrating the CampusLib application during project evaluations.

---

## Presentation Sequence

1. **Admin Login:** Log in as an Administrator.
2. **Dashboard Overview:** Display dashboard statistics (Total Books, Members, Active Loans, Overdue Loans).
3. **Add Book:** Navigate to Books and add a new book record.
4. **Edit Book:** Edit the details of the newly created book.
5. **Search Book:** Search for the book by title or author.
6. **Add Member:** Navigate to Members and register a new student member.
7. **Logout:** Log out of the Admin account.
8. **Student Login:** Log in using a Student account.
9. **Borrow Book:** Search for the newly added book and initiate a borrow request.
10. **Verify Copies:** Confirm that available copies for that book decreased by 1.
11. **Check Active Loans:** View the student’s active loan screen to verify the record.
12. **Logout:** Log out of the Student account.
13. **Admin Login:** Log back in as Administrator.
14. **Process Return:** Navigate to Loans and process the return of the borrowed book.
15. **Verify Return:** Confirm that available copies for the book increased back by 1.
16. **Updated Dashboard:** Return to the Dashboard to display updated stats and recent activity logs.
